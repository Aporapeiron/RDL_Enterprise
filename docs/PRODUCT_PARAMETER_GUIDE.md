# RDL Enterprise 業務AI 動作特性設定

*利用者向け説明 / DRAFT v0.1*

## この設定は何を変えるのか

RDL Enterpriseでは、AIが何を正しいとするかではなく、有限境界の中で仕事をどう進めるかを調整する。通常利用者向けの候補は次の5軸である。

1. **違いへの感度**: 大らか / 標準 / 繊細。予測と後続観測の小さな差をどの程度「対応すべき変化」として扱うか。
2. **関係を見る広さ**: 絞って見る / 標準 / 広く見る。同じ段階で周辺案件・規則・依存関係を何件まで判断材料にするか。深さや重みは変えない。
3. **人への確認**: 自走寄り / 標準 / 確認重視。confidence不足をどの程度早く人へ戻すか。不足・構造衝突・権限上の必須確認を無効化する設定ではない。
4. **見直しの早さ**: 現状維持寄り / 標準 / 早めに見直す。不整合の蓄積から再検査へ進む境界を調整する。不整合そのものやHを消す設定ではない。
5. **知識の定着**: 慎重に定着 / 標準 / 早めに馴染ませる。新しい候補を再利用対象へ進める慎重さ。

これは正しさや真実性を直接変更する設定ではない。権限上必須の承認を省略することもできない。
反応しない設定でも、観測された違いそのものを存在しなかったことにはしない。

## RDLの境界

```text
UNKNOWN ≠ UNRESOLVED ≠ NOT_EVALUATED
Observation ≠ Candidate ≠ Commitment ≠ Active
Authority ≠ Truth
一度うまくいった ≠ 自動的に確定知識
```

高感度にしても常に正しいとは限らず、確認や処理コストが増える場合がある。業務ごとに適した設定は異なる。

## Basic / Advanced

通常画面では5軸を低・標準・高の3段階程度で表示する。管理者・検証担当向けのAdvanced設定では内部閾値や重みを扱う想定で、個別変更時はBasic表示を「カスタム」とする。Basic presetの再選択では対応するAdvanced値へ戻す。

## 将来の調整

初期段階は手動調整を基本とする。

```text
設定変更 → 実務観測 → 結果記録 → 比較 → 次の候補
```

将来AIが変更候補を提案する場合も、候補形成・検証・明示採用を経る。自動最適化や自由な自己変更は本書の対象外である。

## 実務観測

案件完了率、人間介入、作業時間、手戻り、見逃し、誤検知、再編、回帰、コスト、レイテンシを軸ごとに観測する。「高いほど良い」とは仮定しない。

## 未確定事項

5軸の最終性、preset数値、Advancedへの変換式、業務別推奨値、relation depthの有効範囲、相互作用、自動調整の安全範囲、実務コスト優位性は未確定である。

> RDL Enterpriseの動作特性パラメータとは、T0の意味境界を変更せず、有限Boundary内で業務AIが「違い・関係・人間確認・見直し・知識定着」をどの程度強く扱うかを調整する製品層の操作変数である。
